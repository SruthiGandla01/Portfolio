## 🚀 Overview

This is my personal portfolio website built with React. It showcases my recent projects, technical skills, certifications, and resume — all in one place. You can fork this repo and customize it to build your own!

## 💻 Built With

This project uses the following technologies:

- React.js
- Node.js
- Express.js
- CSS3
- React-Bootstrap
- VS Code
- Vercel

## ✨ Features

- 📖 Multi-Page Layout
- 🎨 Responsive design with custom color palette and styling
- ⚙️ Reusable components
- 📱 Fully Mobile Responsive
- 🖼 Certifications and projects dynamically rendered

## 🛠 Getting Started

To run this locally, clone the repository and follow these steps:

### Installation

```bash
npm install
```

### Start the App

```bash
npm start
```

Visit [http://localhost:3000](http://localhost:3000) in your browser.

## 🧩 How to Customize

- Open `/src/components/`
- Update text, images, links, and project content in relevant files (e.g., `Projects.js`, `About.js`, `Experience.js`)
